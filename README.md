### Muhammad Ahmed Mushtaq

Doctoral candidate in Biotechnology at BTU Cottbus–Senftenberg (DAAD fellow). I study the alpha-hemolysin of *Escherichia coli* and its role in pathogenesis, at the bench and with computational biology, and I build reproducible analysis pipelines in Python and R.

**Selected projects**

- [PDAC-RNA-Protein-Concordance](https://github.com/AhmedI0/PDAC-RNA-Protein-Concordance): mRNA–protein agreement, subtypes and survival in the CPTAC-3 pancreatic cancer cohort. Python clients for the NCI GDC REST and PDC GraphQL APIs, an SQLite sample database, R/Bioconductor statistics, pytest and testthat suites.
- [ScRNA](https://github.com/AhmedI0/ScRNA): single-cell atlas of idiopathic pulmonary fibrosis (132,455 cells, 30 donors) with independent replication in 227,434 cells; packaged as a tested Python library with executed notebooks.
